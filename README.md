# Prove It 🎮

Prove It is a peer-to-peer gaming competition platform concept designed to let players compete against one another in games and challenge-based competitions.

## 🌐 Live Demo

Explore the website here:

https://proveit-six.vercel.app

Use the demo button at the bottom-right corner of the website to navigate the user-facing pages without creating an account.

## ✨ Features

- Interactive user interface for a gaming competition platform.
- Demo mode for exploring the website without signing up.
- Multiple user-facing pages and navigation flows.
- Feedback form for visitors to share their opinions.
- User authentication and backend development in progress.
- Admin console currently under development.

## 🛠️ Tools and Technologies

- React

- Vercel

## 🚧 Development Status

Prove It is an ongoing personal project.

The frontend is deployed and available for exploration. Backend functionality and the admin console are still under development.

Some features displayed in the interface may not yet be connected to a functioning backend.

## 🎯 Project Goal

The goal of Prove It is to explore how players can participate in competitive gaming experiences and challenge other players through an accessible digital platform.
